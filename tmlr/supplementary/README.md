# Supplementary machine-readable materials

This lightweight archive accompanies the manuscript.

- `activity_inventory_18.csv` contains the final 18-activity reporting vocabulary, reporting-corpus counts, definitions, input/output fields, distinct-from contrasts, and the final merge note for procedure-execution.
- `validation_summary.csv` contains the five validation checks reported in Appendix A.

The full 12,464-task O*NET assignment file and item-level ESCO mapping file are larger derived artifacts. The manuscript commits to releasing those files with the final archival version.
